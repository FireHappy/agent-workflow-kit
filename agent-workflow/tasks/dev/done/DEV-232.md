### 现象
启动日志：`[dsh-better-sidebar] native register awf-dashboard error: sidebarRight: tab kind "awf-dashboard" is already registered (extension)`。用户确认「我们现在的插件是不是可以不用注册侧边框了」。

### 结论（已证）
better-sidebar 0.28+ 的 `registerNativeSurface.sync()` 会把 `registerTab()` 注册的所有外部页签自动镜像为原生 `sidebarRightTabs` kind（id/kind 同值、`priority: extension`、body 直接渲染插件传入的 `component`）。本插件 DEV-226 又自注册同名 kind → 宿主重复注册抛错（先注册方赢，后注册方报错）。

修复：原生 kind 自注册**只在没有 better-sidebar 的宿主原生右栏环境**执行；判定延迟一拍（better-sidebar 的 service 在 apply 期可能未 provide），并加 `tabs.get('awf-dashboard')` 存在性校验兜底。

### 验收标准
- [ ] better-sidebar 在场：插件不调用 `sidebarRightTabs.register`（日志无 already registered；无 2 个重复的 tab 类型/guide capsule）
- [ ] 无 better-sidebar：插件仍自注册 kind，`sidebarRight.openTab('awf-dashboard')` 可达（宿主原生右栏兜底不回归）
- [ ] 单测：新增 2 组（有/无 better-sidebar 两路径）全绿；全套 58/58
- [ ] 版本 1.8.0→1.8.1 + CHANGELOG；sync-profile 同步已安装副本；check_workflow 通过；本地 commit 未 push
