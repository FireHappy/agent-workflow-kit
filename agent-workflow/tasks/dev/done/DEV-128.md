### 目标
用户反馈：派发任务有时确实需要继续向下一层派发。去掉 DEV-115 的「派发深度=1 / 来源=工作流禁转派（FAIL exit 2）」硬校验，改为允许按需转派（深度不限），仅提示核对转派理由并更新票据「路由裁决」保持链路清晰。

### 方案
- awf-dispatch：main 中原 raise DispatchError（禁止转派）→ 非阻塞 emit 提示（票头来源=工作流时提示「深层转派，DEV-128 已允许」）；ticket_source docstring 与文件头注释同步；--help epilog 更新。
- templates/AGENTS.md.tmpl 第 0 条：激活时机改为「节点需要执行 or 派发决策时临时激活」；新增「允许继续转派（DEV-128 放开深度限制）」条款，替代「激活条件唯一 / 派发深度=1」。
- workflows/cross-project.md：来源=工作流说明与第 2 条改允许转派。
- docs/design.md：激活条件/深度/拓扑（DAG 留痕）/示意二同步。
- docs/dispatch.md：票据模板注明与「ticket_source」校验段改提示。
- smoke：21 段 python 断言反转（来源=工作流二次派发：不再 FAIL/禁止转派，断言提示「深层转派」+ 走到 G1 预检门）；21.2 grep 断言改查「允许继续转派 / 不再 FAIL 拦截 / 按需继续向下一层」；新增 design.md 同步断言。总计 170 项。
