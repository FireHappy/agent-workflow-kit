### 目标

修改派发契约：目标 worker 需要用户确认/决策/补充信息时，**不得在目标会话内向用户提问（ask_user_question 等）**；改为在会话内回报「阻塞：需用户确认 X（问题 + 选项 + 建议 + 解除条件）」并保持等待；由派发方（router）转述用户、拿到决策后 `awf-dispatch --session <会话ID>` 续发决策给 worker 继续。同时要求**阻塞待决策时不得擅自执行推荐方案**。不改变：默认异步、必有回报、生命周期、G1–G4、会话标题规范。
