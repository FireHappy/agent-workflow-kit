### 目标

把 dsh-awf-dashboard 的 `copy-workflow-assets.mjs` 技能源从「本机已安装实体 ~/.dsh/skills/agent-workflow-scaffold」收敛为「仓库（或发布 tag）」，使 npm 包内嵌技能 = 发布版本的技能、可复现可校验：

1. 打包内容与发布版本强绑定：manifest 不再写死本机源路径（当前 skillSource 是 /Users/chenlin/...）。
2. 发版前无需先 install.sh 同步本机实体（现状：实体旧则包内技能旧；--skill-dir 指向仓库根会误内嵌 .agent-teams/**）。
3. 其他用户 `dsh plugin add` 拿到的技能与 CLI 同一版本来源，--check 对发布包有效。

### 背景（DEV-216 memory/history 已记）

- 插件 1.6.0 已内嵌 24 项技能文件（npm pack 验证），但内容 = 实体 1.6.0（DEV-216 前规则），CLI = 仓库最新——源不同步的产物。
- copy 脚本源设计：技能 ← 实体；bin/awf ← 仓库。需统一为「仓库为唯一源（或发布 tag 快照）」。

### 验收标准

- [x] copy 脚本技能源改为仓库（或 --skill-dir 显式指向仓库内技能目录），manifest.source 记录发布版本（package.json version / templates 骨架版）而非本机绝对路径
- [x] 仓库根 .agent-teams/** 不会被当成应内嵌文件（白名单收集，--check 不报 DRIFT）
- [x] 打包产物 = 当前发布技能的快照：--copy → --check 一致（21 文件逐文件 sha256）；插件版本 1.7.0、骨架版 1.5.0
- [x] 版本契约：FRAMEWORK_VERSION 移入 templates/（根 + agent-workflow 副本）；init/upgrade 读模板；插件版本信号读 package.json；实体根 VERSION/FRAMEWORK_VERSION 退役（install.sh 不写并清理）
- [x] 插件内嵌布局平铺：skills/agent-workflow-scaffold/（框架）与 8 个流程技能同级，不再嵌套 skills/

### 实现记录（2026-11-08）

- copy-workflow-assets.mjs 重写：源 = kit 仓库白名单（SKILL.md / skills/* / templates/* / test/* + bin/awf）；产物平铺；manifest.source.{version,frameworkVersion}；--check 逐文件 sha256 + 版本契约漂移；awf.path 固定为仓库内路径。
- 版本契约：新增 templates/FRAMEWORK_VERSION（与 agent-workflow/templates/ 副本一致）；bin/awf init/upgrade 的 kff_src/KFF 改读 templates/FRAMEWORK_VERSION（实体优先，回退 kit）；lib/index.js kitVersions 的 skillVersion 改读插件 package.json、latestFramework 改读 templates；install.sh 移除实体 VERSION/FRAMEWORK_VERSION 写入并清理旧文件。
- 插件 1.6.0 → 1.7.0（破坏性：布局 + manifest 契约 + 版本信号）；README 更新「内嵌技能/CLI 副本」节与变更记录。
