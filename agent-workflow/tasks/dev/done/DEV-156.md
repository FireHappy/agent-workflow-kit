### 目标

实现「回报通道」：目标会话按必报点（DISPATCH-145 10 点 + 转派链 + mid-status）回报时，awf-dispatch 自动把回报**投递到派发方会话**（不经派发方轮询），主通道 = harness RPC 推送进派发方会话收件箱（inbox，自动触发其回合），降级通道 = 收件箱文件 `dispatch/reports/inbox/`；回报内容仍按必报点表组织（说什么不变，通道负责怎么送达）。
