### 目标
修复 awf-dispatch 满池监听等待逻辑四缺陷：
1) 本地归档台账（dispatch/archived-sessions.json）：组装复用池/统计每项目 [awf] 会话数时排除已归档会话 id；新增 --forget-archived 重置台账。
2) --new 上限校验：目标项目 [awf] 池≥3 且全忙时，--new 需 --allow-over-3 显式确认并留痕。
3) 并发新建互斥：同项目新建决策用文件锁（dispatch/.lock-<project>）串行化，锁后重读池再决策。
4) --cleanup：列出每项目超 3 的空闲 [awf] 会话，经 workspace/archiveSession 归档并写入台账。
SKILL 参数表与机制说明同步；smoke 补断言。
