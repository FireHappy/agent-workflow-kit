# 熄屏判定：决策通知路径（DISPATCH-143，DEV-150）

日期：2026-11-05。目标：工作流在「需用户确认」决策点时先判本机（macOS）是否熄屏——熄屏（用户不在）→ 决策请求不原地死等，照常回报「阻塞：需用户确认 X」并标记「远程办公状态（remote）」，由派发端经 IM 主动、立即通知用户决策；亮屏 → 原 DISPATCH-141 路径。**熄屏只改通知路径，不代答**。

## 实现与判据

- `bin/awf-dispatch`（与 agent-workflow/bin/awf-dispatch 双副本同步）：
  - `detect_screen_state()` → on（亮屏）/ off（熄屏）/ locked（锁屏）/ unknown（未知）；非 macOS 直接 unknown。
  - 锁屏：CoreGraphics `CGSessionCopyCurrentDictionary` 的 `CGSSessionScreenIsLocked`（pure stdlib ctypes）。
  - 熄屏：`pmset -g log` 最近一次 `Display is turned off/on` 转事件中较新者（日志按时间序、行前缀定宽 `YYYY-MM-DD HH:MM:SS`，同偏移下字典序=时间序）。
  - 失败保守 unknown，绝不误报亮屏。
- CLI：`awf-dispatch --screen-state`（打印四态之一，--json 输出 `{"screen_state": ...}`，RC 0，不派发；与 --prune/--session/--headless/--handoff/位置参数显式互斥）。
- 注入文本：build_prompt 补充约定新增条款——需用户确认前先跑 `awf-dispatch --screen-state`；off/locked＝远程办公状态（remote）→ 照常回报阻塞 + 注明「远程办公状态（remote），请派发端经 IM 主动、立即通知用户决策」，保持等待不擅自决策；on → 原路径；unknown → 注明由派发端酌情。
- 派发端侧：收到 remote 标记 → 经 IM（飞书）主动、立即通知用户决策 / 置待决队列（派发方账本 + dispatch/log.md 登记防遗忘锚点）→ 用户决策后 `awf-dispatch --session` 续发。
- 文档/模板同步：docs/dispatch.md、docs/design.md、templates/workflows/cross-project.md（双副本）、templates/AGENTS.md.tmpl（双副本 → bootstrap）、skills/cross-project-dispatch/SKILL.md、AGENTS.md（受控区块 + 区块外协作约定）。术语统一为「远程办公状态（remote）」。

## 坑与教训

1. **CoreGraphics ctypes 直接调用在本机段错误**（CFDictionaryGetValue 指针传递在 arm64 不稳，LoadLibrary/调用都会崩）：探针必须**子进程隔离**（`sys.executable -c` + timeout），段错误只杀子进程（rc=-11）、绝不崩派发器主进程；锁屏探测失败自动退化为按熄屏处理（off 同样触发 remote 路径）。
2. **`pmset -g log` 是熄屏判定最稳的数据源**（本机实测 38 条 Display 事件、最后事件 21:07 off 与 CLI 输出一致）；跨时区偏移/同秒双事件理论误序，判据不敏感，代码注释已注明。
3. **术语统一由外部会话并行落地**：我初版用「用户暂离（熄屏）」，外部会话统一改为「远程办公状态（remote）」并升级 smoke 30.9b（查「用户暂离/away」残留）。同一工作树并行修改同一批文件时，验收措辞以最终磁盘状态为准，提交前必须重新 diff/复跑（此轮 smoke 曾 199/2 撞上对方瞬时写入，重跑后 202/0）。
4. smoke 新增 §S5（解析器 fixtures：熄屏→亮屏=on / 亮屏→熄屏=off / 无事件=None；detect_screen_state ∈ 四态；CLI --screen-state 与 --json 子进程实测不崩）+ §30.9/30.9b（注入文本与文档/模板同步 + 术语统一）。grep 模式以 `--` 开头会被当作选项，用 `grep -q -- '--screen-state'`。
5. 验收结论：REVIEW-D143 通过（2 minor 均已处理：--screen-state 显式互斥校验；解析注释注明限制）。smoke 202/0 双 locale、check 全绿、三对副本 diff 空。
