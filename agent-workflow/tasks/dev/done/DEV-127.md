### 目标
任务账本按任务拆文件：`tasks/<type>/{todo,current,done}/<ID>.md` 单任务文件（状态=所在目录），三个目录各一个 `README.md` 作为检索索引（由 `awf status` 生成）；dev/debug/docs 三类型统一；旧大文件（含块 done.md / todo 表行）由 `awf status` 自动迁移为目录式。

### 验收标准
- [x] 三目录结构 + 每目录 README.md 索引（todo=ID/优先级/标题/登记日期，current=ID/优先级/状态/Owner/标题，done=ID/优先级/标题/完成日期），由 `awf status` 重生成（"请勿手改"标注）
- [x] 认领 = 文件从 todo/ 移到 current/ + 状态字段改 active；归档 = current/ → done/ + 状态 done + 补完成日期（`awf release-prep` 自动归档）
