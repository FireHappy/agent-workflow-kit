### 目标
- 显式双版本：技能版本 Skill-Version = agent-workflow/VERSION（每次发版 bump，插件显示、技能实体安装消费）；骨架版本 Framework-Version = agent-workflow/FRAMEWORK_VERSION（新增，仅骨架契约变化 bump，awf upgrade 判定与插件 outdated 消费）。
- upgrade 按骨架版本差量判定：相同 → 跳过（--force 强刷）；不同/缺失 → 复制骨架 + 补写项目 FRAMEWORK_VERSION；**不再把 kit 版本覆写到项目版本锚点**。
- 插件显示技能版本为主，项目 outdated 只看骨架版；存量项目回退旧判定并在 upgrade 时迁移补写。

### 已确认决策（用户拍板）
1. FRAMEWORK_VERSION 落点 = 独立文件 agent-workflow/FRAMEWORK_VERSION（kit 与每个框架项目各一份），project.yaml 不加键、version_file 机制不动。
2. upgrade 骨架版本相同即跳过，--force 强刷。
3. 本任务只落地 kit+插件+测试；10 个登记项目迁移另行派发（与 DEV-194 合并）。
