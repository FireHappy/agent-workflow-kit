### 目标

把 dsh-task-ledger 值得借鉴的 5 项落到 agent-workflow-kit（分三条实现轨 + 交叉复核）：

1. **账本 CLI**（t1，impl-a）：bin/awf 新增 `log` 子命令（任务文档 Execution Log 节只增不改、由脚本追加）+ `validate` 子命令（只读一致性体检）；任务模板与骨架生成增加 Execution Log 节；smoke 断言。
2. **技能与纪律**（t2，impl-b，依赖 t1）：dev 技能「收工三步」（改正文→awf log→回读末行）、改正文必配 log；删除只认「删除」原话+二次确认、取消/暂停/结案区分、建任务触发语义细化进技能规则块与 AGENTS.md。
3. **插件单源化 + 派生指标**（t3，impl-c，依赖 t1）：dsh-plugin 内嵌技能/CLI 副本（装插件即装工作流，防解析规则漂移）；ledger.js 派生停滞(3天)/逾期(7天)只读字段、看板行内小徽章。
4. 交叉复核：t1↔t2↔t3 由不同实现者复核（t4 复核 t2、t5 复核 t1、t6 复核 t3），独立重跑验证。
