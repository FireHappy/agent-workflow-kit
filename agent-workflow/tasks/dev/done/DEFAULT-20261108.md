### 目标

用户确认会话逻辑：默认就是「每次新建」，完成后先归档再删文件。把 `awf-dispatch` 的
`DEFAULT_REUSE` 从 True 改为 False，`--reuse` 变为显式逃生口；`--new` 保留为兼容写法。
同时修正依赖「默认复用」的互斥校验：`--session` / `--cleanup` / `--retire-session` 不再因为
默认 `reuse=False` 而误报，改为只在用户**显式**写 `--new` 时才互斥。

### 改动

- `DEFAULT_REUSE = False`；`--reuse` 帮助改为「显式复用」；`--new` 标为兼容/默认。
- 新增 `args.explicit_new`（扫描 `--new`），三处互斥校验改用它。
- 帮助/描述文本：默认新建、完成后 `--retire-session` 归档 + `dsh-session-gc` 删文件。
- SKILL.md：脚本行为、会话命名/池语义、命令行参数、满池治理均标注「仅 --reuse 时」。
- test/smoke.sh：默认断言改为 `DEFAULT_REUSE is False`。
