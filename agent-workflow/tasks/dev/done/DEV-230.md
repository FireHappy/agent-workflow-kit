### 目标

1. **启动确认（发送成功 ≠ 真的启动）**：派发后等待 `--launch-timeout`（默认 15s；0 关闭），以 `running=True` 或 `asOfSeq` 推进判定启动；未启动 → 写入坏会话隔离台账（`<cwd>/.dispatch/quarantine-sessions.json`，TTL 1h）+ `workspace/archiveSession` 归档 + **自动新建会话重发一次**；仍失败报错（不静默丢任务）。
2. **复用候选健康度**：`agentAvailable=false` 或隔离期内的会话不进复用池、不占「每项目 ≤3」新建名额。
3. **测试**：smoke 新增 DEV-230 单元块；e2e 新增 S7（真实隔离台账过滤）、S8（真实坏会话模拟，宿主未复现则 SKIP 并说明）。

### 实现记录（本会话）

- `confirm_session_started()`：`running=True` 或 `asOfSeq` 推进 → 已启动；超时 → 未启动。
- `quarantine_session()` / `load_quarantined_session_ids()` / `session_usable()`：本地隔离台账（TTL），池筛选跳过坏会话。
- `pick_claim_session` / `select_reuse_session`：过滤 `agentAvailable=false` 与隔离中会话；限额判断用「可用池」数量（坏会话不占名额）。
- `dispatch_session`：`prompt` 后确认；未启动 → 隔离 + 归档 + `create_session` 新建重发一次；新建仍未启动 → `DispatchError`。
- 新增参数 `--launch-timeout N`（默认 15；0=关闭）。
- SKILL.md：脚本行为、参数表补充启动确认/健康度说明。
