### 目标
目录式账本下，用户在面板点击某任务（最近完成/当前/待办）打开的应是**该任务单文件详情**，而不是整个桶的 README 检索索引（后者此前导致"点一个任务看到所有任务"）。

### 验收标准
- [x] GET /awf/source 支持可选 id：目录式下 `tasks/<type>/<桶>/<ID>.md` 单任务读取；不带 id 仍返回桶 README（整桶视图保留）；id 非法 400 bad-id；缺文件 404（文案带目录式路径提示）
- [x] 前端最近完成/当前任务/待办行点击自动携带任务 id（fetchSource/openSource 透传）
- [x] 旧形态（大文件）项目不受影响（id 忽略）；readSource 保持只读（目录式 writeSource 仍拒绝直写）
- [x] 测试 33/33 全绿（新增 2 个 DEV-132 用例）；kit 真实账本冒烟：带 id → done/DEV-127.md 单任务、无 id → done/README.md 索引
- [x] 版本 0.3.1 + README 变更记录

### 完成情况（2026-11-04）
- 根因：DEV-129 目录式适配把 readSource 的"桶源文件视图"实现为桶 README 索引，前端点击任务行沿用桶粒度请求 → 显示全部任务列表
- 修复：三处联动（ledger 读路径 + index 路由透传 id + client 点击带 id）；双向兼容（legacy 忽略 id）
- 用户侧：需 `dsh plugin update dsh-awf-dashboard`（宿主加载 0.3.1）或重启 DSH 后生效，刷新面板点已完成任务即显示该任务详情
