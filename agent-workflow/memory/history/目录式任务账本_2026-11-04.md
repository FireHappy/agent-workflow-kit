# 目录式任务账本（DEV-127）设计与迁移记录

<!-- long-term: true -->

## 背景

- 旧形态：`tasks/<type>/{todo,current,done}.md` 大文件（含块 done.md 可达 1000+ 行）；面板/agent 读大文件干扰大、单文件难检索
- 用户设计（2026-11-04）：`tasks/<type>/{todo,current,done}/` 三目录 + 每目录一个 `README.md` 作检索索引；dev/debug/docs 三类型统一

## 核心约定（事实源 + 状态=目录）

- 事实源：`tasks/<type>/{todo,current,done}/<ID>.md` 单任务文件（`## [ID] 标题` + 字段表 + 验收标准 checkbox + 下一步）
- 状态=所在目录；认领 = todo/ → current/ 移文件 + `| 状态 |` 改 active；归档 = current/ → done/ + 状态 done + 补 `| 完成日期 |`
- 三目录 `README.md` 为**检索视图**（由 `awf status` 生成，含"请勿手改"标注），不是事实源
- status.md 直接扫任务文件生成 → 账本改动未跑 `awf status` → check 报「已过期」（F2 新鲜度语义保留）

## 迁移（awf status 幂等，可反复跑）

1. 含块大文件（`## [` 开头）→ 逐个 ID 拆为单文件（写前 `test -f` 跳过已存在=幂等；**完成判定=所有块 ID 都有文件**才删旧大文件，防误删半成品）
2. todo.md 表行（`| ID | 优先级 | 描述 | 日期 |`）→ 生成待办文件（**仅 todo.md**；done.md 的 summary 表是历史记录不生成；ID 已存在于 current//done/ 的残留行跳过）
3. 历史状态值归一：archived/完成/Archive → done（新枚举 todo/active/blocked/review/verify/handoff/done 严格）
4. 空表（`（空）` 或无表）→ 删除对应旧文件；块尾裸行清理（ledger_cleanup_files）

## 踩坑（bash 3.2 + UTF-8）

- `$VAR（`（变量名紧跟全角括号）→ bash 吞括号字节进变量名报 unbound：一律 `${VAR}（`
- awk 中文键比较（`trim($2) == "优先级"`）在 en_US.UTF-8 下**恒真**（多字节 == 的问题）→ 统一 `awfk`（LC_ALL=C 包装）；task_field/task_title/task_id 全走 awfk
- `sort -t'|' -k5,5r`（done 段日期排序）在 en_US.UTF-8 与 C 排序不同 → status.md 与 check 重渲染 diff 不一致 → 误报"已过期"：sort 固定 `LC_ALL=C`
- python glob 不支持 `{a,b}` brace 展开 → 用显式目录循环

## 插件适配（DEV-129，dsh-awf-dashboard 0.3.0）

- 读：ledgerOf 目录式优先（current 桶逐块 / todo 桶进度+结构化行 / done 桶块式归档，parseDoneRows 归档白名单加入 done）；旧大文件兼容回退
- 写：startTask/returnTaskToTodo/todoEdit/deleteTask/taskEdit 目录式（移文件+改状态）；readSource 返回桶 README；writeSource 目录式拒绝直写
- 9 项目迁移前后插件零改动可用

## 配套

- release-prep 自动化：release_write_current → current/<TASK_ID>.md；release_archive → mv done/ + 状态 done + 完成日期
- check：F1 枚举校验、F3 三目录扫描 + F3b 旧文件兼容、required 9 个目录 README（缺目录提示旧形态兼容）
- smoke 第 28 节：目录式生命周期断言（todo 登记 → 认领 current/active → 归档 done/+完成日期 → README 同步 → check）
