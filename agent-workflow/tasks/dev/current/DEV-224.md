### 目标

1. 入池规则：目标项目 cwd 匹配 + 标题 `[awf]` 开头 + 未归档（去掉 blank=False 过滤）。
2. 选择：池内 `running=False` 取一个复用（多个取最新）；都忙 → 排队等任一空闲（默认不新建，`--new` 显式逃生）。
3. 并发：全局登记表（`$DSH_HOME/.awf-dispatch/sessions.json`）+ 文件锁，防两个派发同时选中同一空闲会话；发送后冷却，靠 running 接管。
4. 移除每项目 3 个并发上限（over_limit_guard / --allow-over-3 行为）。`--cleanup` 保留用于存量收敛。
