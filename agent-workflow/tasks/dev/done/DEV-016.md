### 目标
registry_lock 优先 flock（锁文件常驻不删除），无 flock 时退化 mkdir 自旋锁（释放时 rmdir 删除锁目录）。测试尾部 `[ ! -e .awf-registry.lock ]` 在 flock 平台会误报失败：改为按实际锁模式分支断言——mkdir 模式断言无残留；flock 模式断言锁文件存在且可正常获取/释放。
