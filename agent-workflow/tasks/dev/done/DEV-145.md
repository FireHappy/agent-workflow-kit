### 目标

修复 awf 版本锚点与 Unity IL2CPP 编译头文件撞名：macOS 大小写不敏感 FS 上，目标仓库根出现文本文件 `VERSION`（含 `1.1.1`）时，Bee clang `-I"."` 会把 `#include <version>` 解析到该文件，报 `expected unqualified-id` 并级联误报（uxrsample 2026-11-04 实测：改名 VERSION→VERSION.bak 即构建成功 207s/0 错误）。release-prep 与 init/upgrade（DEV-133 锚点同步）的版本锚点读写一律改读目标 `agent-workflow/project.yaml` 的 `version_file`，**默认仍为仓库根 VERSION**（未配置的项目行为完全不变）；文档说明锚点不得放进 clang 头文件搜索路径。
