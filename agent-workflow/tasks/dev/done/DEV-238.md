### 目标

把 kit 骨架 1.5.2（AGENTS 模板补充本地技能按项目定制说明）派发到 10 个已登记项目，由目标 agent 在本仓库执行 `awf upgrade` 并本地提交。

### 方案

逐项目 `awf-dispatch --sender agent-workflow-kit` 异步派发；G3 有脏/active 的项目加 `--allow-dirty` / `--allow-active`。

### 验收标准

- [ ] 10 个项目均收到派发（或明确跳过理由）
- [ ] 目标回执「FRAMEWORK_VERSION=1.5.2 + check rc=0 + commit」
- [ ] 派发方核验后归档本任务

### 下一步

写票据 → 逐项目 dry-run → 派发 → 收集回执核验 → 归档

### 结果概要

- 骨架 1.5.2 已 bump（kit commit 07587b2）。
- 派发尝试：10 张票据齐备，G3 通过（--allow-dirty/--allow-active），但 GUI 通道 G4 失败（桌面端 Cookies 库 127.0.0.1 认证 cookie 为 0 行）；按用户选择改 --headless 派发，10 个 headless 会话全部 `ACCOUNT_QUOTA: Insufficient Balance` 未开工。
- 用户选择「直接逐项目本地升级」→ 10 个项目已全部 `awf upgrade` 到 1.5.2，`check_workflow.sh` 全部 rc=0。
- 提交：openxr-uxr 0f142c4、finderpathbar 13e4d9e、周报 fcc7b90、im 866fe5a、dsh-settings 66830da、uxrsample 9d2f03e8；rokid_system_components / pluto / naboo / renderlib 的 agent-workflow 被 .gitignore 忽略 → 磁盘已升级、无提交（与 1.5.1 轮一致）。
- 未动他人业务改动（周报 .weekly_raw_data.md/generate_weekly_report.sh、uxrsample RKImage.db / ProjectSettings / 任务账本变动、rsc 的 Unity 资源、naboo 的 Unity 项目、renderlib 的 PointCloudRenderPass.cs）。
