### 目标
会话标题一眼可辨「谁派的、做什么」：`[awf] [派发者] [任务名]`；同时会话数收敛：同派发者同项目最多 3 个，空闲复用、满了才等。

### 验收标准
- [x] 标题格式 [awf] [派发者] [任务名]：派发者 = --sender > 票据「派发者：」行 > lead；任务名 = ID + 短标题（task_display，截断 40）
- [x] 复用池：同 cwd + 标题派发者段 == 本次派发者（段级精确匹配，避免 [lead] 吞 [leadership]）；旧格式 [awf] <项目> 归 lead 池平滑升级
- [x] 并发上限：池内空闲优先复用；都忙且池未满（<3）新建；池满（=3）都忙 → 等待（--queue-timeout，默认 60s）
- [x] 不做完成还原（最新任务名保留可辨）
- [x] --title 完全定制优先；--sender 参数 + 帮助/文档同步
- [x] 测试：smoke 176/0（会话复用段全部重写为新模型）；dispatch 标题单测 25/25（新 test/test_dispatch_title.py）
- [x] docs/dispatch.md 命名/复用段落同步；memory 沉淀
