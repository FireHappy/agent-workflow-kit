### 目标

把派发协议修正为三条规则：

1. **异步默认**：awf-dispatch 默认异步派发（只发送、立即返回会话 ID），主会话不被钉住；`--wait` 是显式开关（需要本回合结果/落地确认时才加）。
2. **派发即启动子代理**：派发动作的实质=在目标项目工作区启动一个子代理会话，由目标 agent 独立执行；**不启用智能体团队承载派发**（去掉 captain/dispatcher 成员层）。
3. **票据瘦身 + 分析归 worker**：router 只写 用户意图 / 硬约束 / 验收标准 / 路由裁决，**不写执行步骤、不做前置侦察**（build_guide/历史产物/场景清单等）；前置分析由目标 worker 在自己的会话里用目标仓库 tools/ 手册与 memory/history 完成，有疑问返回 router / 用户决策。

不改 awf-dispatch 行为代码（异步默认 DEV-126 已实现，无需参数默认值变化；--team 保留为显式 opt-in 的目标侧建议）。
