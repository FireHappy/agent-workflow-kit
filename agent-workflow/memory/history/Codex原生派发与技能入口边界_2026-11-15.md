# Codex 原生派发与技能入口边界（2026-11-15）

## 结论

- 技能文件和脚本入口统一使用 `${AGENTS_HOME:-$HOME/.agents}/skills/<skill>`；`DSH_HOME` 只承载 DSH 运行时状态、会话和派发登记数据。
- Codex 原生派发必须先用 `list_projects` 对目标绝对路径做精确匹配；`create_thread` 返回 `clientThreadId` 时只能记为 queued，不能当作已启动。
- `create_thread` 失败时保留原始错误，不自动重试或重复建线程。只有用户明确允许后，才把失败原因和授权记录到 `.dispatch/log.md` 并回退 DSH。
