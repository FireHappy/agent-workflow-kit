### 目标

给工作流增加 macOS 熄屏状态判定（DISPATCH-143），并按用户定义升级（2026-11-05）落地语义：**熄屏不是「用户暂离」，本质状态是「远程办公状态（remote）」**——本机熄屏且用户在 IM（飞书小迪司）在线可联系 = 用户不在电脑前、但通过远程 IM 通道在线、随时可决策。目标会话遇「需用户确认」决策点时先检测本机是否熄屏：熄屏（远程办公状态）→ 照常按「阻塞：需用户确认 X（远程办公状态，请经 IM 通知用户决策）」回报派发端并保持等待，派发端**主动、立即**经 IM 送达决策（用户手机即可决策）——这是远程办公正常流程的一部分，不存在「等待用户回来」的被动态；亮屏 → 原 DISPATCH-141 路径。两条路径都是「正常就绪」状态。**熄屏只改通知路径，不代答**。
