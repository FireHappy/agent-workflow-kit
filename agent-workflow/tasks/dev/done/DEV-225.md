### 背景

派发器长期在本地堆积文件：本仓库 `.dispatch/` 18 个文件、log.md 987 行；7 个目标项目根部各有 `.dispatch/reports/*.json`（回执逐个落盘，共 27 个）；锁文件 `.lock-*` 残留。

### 改动

1. **回执默认不落盘**：`--report` 走通道投递即可，不再逐回执写 `.dispatch/reports/*.json`；需审计时显式 `--save-report`。
2. **锁文件全局化**：`project_lock_path` → `$DSH_HOME/.awf-dispatch/locks/.lock-<project>`，不再在项目 `.dispatch/` 生成。
3. **免票据派发**：新增 `--task-text "<任务文本>"`，直接派发不写 `.dispatch/tasks/`（内部临时文件用完即删）。
4. **日志体积上限**：log.md 超过 120KB 时只保留最近 400 行。
5. **清理存量**：本仓库 `.dispatch` 18→2 文件（只剩 archived-sessions.json + log.md）；log 987→200 行；7 个目标项目 `.dispatch` 全部清空。

### 验证

- smoke **242/0**；install 同步实体；check_workflow.sh 全部通过。
- `--task-text ... --dry-run --allow-dirty` rc=0（G1–G4 全过，无票据文件生成）。
- 7 个目标项目 `.dispatch` 检查均 clean。
