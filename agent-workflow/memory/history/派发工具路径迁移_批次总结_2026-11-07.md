## 背景
DEV-201：派发实现由 cross-project-dispatch 技能自带（scripts/awf-dispatch），脚手架旧入口移除。全量同步 8 个登记项目的 AGENTS.md 派发路径 + 清理存量副本。

## 三个共性发现（复用价值）

### 1. bootstrap 不更新项目内模板
bootstrap 按**项目内 templates/AGENTS.md.tmpl** 渲染入口，不从技能模板取。旧项目模板是 v1.4.0 旧路径时，纯 bootstrap 后旧路径保留——**必须 `awf upgrade`（同步模板）再 bootstrap**。8 个目标全部自己发现并纠正（动作模式 bootstrap → upgrade --slim）。

### 2. serialized 是 upgrade 保留清单外字段
project.yaml 的 serialized（共享写点）含旧工具副本路径（agent-workflow/bin/awf、bin/awf-dispatch）时，upgrade 保留 project.yaml 不覆盖——**需单独清理**：编辑 serialized 移除退役路径 + bootstrap 刷新 AGENTS.md 共享写点行。受影响：openxr-uxr、uxrsample（v1.4.0 时代模板值）；init 补全的新项目无此问题。

### 3. 同票据复用会话续发易被误判「重复派发」
同一票据文件 + 复用会话续发补充指令时，目标看到相同票据易判「重复派发」只核验不执行（openxr-uxr 3 次、uxrsample 4 次）。对策：**独立标题/独立票据文件/新会话**派发补全项，或在指令开头明确「非重复派发 + 确切修改值」。
