# 经验/工具积累闭环（DEV-124）

- 背景：每个 worker 有 memory/{cache,history} 与 tools/ 目录，但积累无闭环（结论留票据、经验没人读）。DEV-124 补闭环，关联任务 [DEV-124]（tasks/dev/done.md）。
- 结论：闭环 = 开工读 history 同类经验 → 执行 → 收尾沉淀结论到 history、脚本按晋升三要素收 tools → `awf check` 软提示兜底（只提示不 FAIL）。
- 实现要点（可复用）：
  - memory/README 与 tools/README 由 `awf init` 的 `write_aux_files`（put_if_absent heredoc）生成，规则在 `agent-workflow/bin/awf` 里改，非独立模板文件。
  - done.md 归档块最小合法结构：`| 状态 |` + `| Owner |` 两行字段即可过 check；summary 行（`| ID | P0-P3 | … | YYYY-MM-DD |`）在块外紧邻块尾。造数块用于 smoke 软提示断言。
  - check 软提示函数 `check_growth_hints` 挂在 cmd_check 的 `return "$fails"` 前，只 say 不计数；条件：归档 ≥3 且 history 无 `*.md` → 提示补沉淀；tools 无脚本 → 提示收录。
  - AGENTS.md.tmpl 开工顺序 3-6 条编号（读历史插在流程加载后、认领前）。
- 验证：三 locale smoke 166/0；PROJ9 造 3 归档 → 提示出现 rc=0；补 history 文件 → 提示消失。
- 坑：done.md summary 行若出现在块内字段表（`| 完成日期 | … |` 这行 $3 非 P0-P3）会被归档行校验误报，实际合法结构是「字段表含完成日期行 + 块外 summary 行」。
