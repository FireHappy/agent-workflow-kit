### 目标

宿主 DSH 0.2.2-rc.1 没有删除接口，官方文档称「日志累积，直到外部移除」。用户要求写工具直接清理。
落地一个安全的外部清理工具，而不是裸 `rm -rf`：

- 默认 `list` 只读盘点（按项目 / [awf] 过滤 / 大小 / 年龄 / 归档 / 运行中）。
- `quarantine --archived --apply`：**只处理 DSH 已归档会话**（先归档再删文件），移入 `~/.dsh/.session-trash/<ts>/`（可恢复），同步移走 `session_projcache`。
- `purge --archived --yes`：永久删除（显式确认）；未归档需 `--allow-unarchived`。
- 拒绝当前会话（`$DSH_SESSION_ID`）与被持锁（运行中）会话；不写 DSH `workspace.json`（运行中写会被宿主覆盖，残留 id 无害）。
