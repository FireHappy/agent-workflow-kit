### 目标与结果
让 awf init 初始化时就能定义项目能力（role 名牌），worker 登记信息一步到位，不依赖事后补填。

### 实现方案
- cmd_init 增加 --role / --role=（照抄 --purpose 解析）；P_ROLE 传入 render()（新增 {{ROLE}} 占位替换，load_project 读回 P_ROLE）。
- templates/project.yaml.tmpl role 块改为注释示例 + `role: {{ROLE}}`：--role 给值写值；缺省保留空键（DEV-119 方案 B 跳过空值，不吞后填值）。
- init 完成时 role 为空 → 输出填写指引提示（有 role 不提示）。
- smoke 23.1 改为「模板源无字面空键 + init 缺省保留空键」；新增 23.3 七条断言。

### 验收标准
- [x] awf init --role 生成的 project.yaml 含 role: <值>，find 立即带出（实测 d121r1）
- [x] awf init（无 --role）保留空 role: 键不报错，find fallback 到 name（实测 d121r2）
- [x] init 完成提示在 role 为空时给出填写指引（实测含提示行；有 role 无提示）
- [x] 模板同步副本无 drift；smoke 断言通过；默认 locale 与 LC_ALL=C 全绿（另验 en_US）
- [x] DEV-121 已归档，check_workflow.sh 全过，status.md 已刷新
- [x] 只本地 commit，未 push
